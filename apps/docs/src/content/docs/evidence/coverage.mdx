Three levels of proof, never mixed up:

- <Status kind="live" /> ran on a public test network; the transaction is on [Evidence](/evidence/).
- <Status kind="offline" /> covered by tests that need no network (mock chain, recorded provider
  responses, the real workers in workerd). Built, but a live run could still find a problem.
- <Status kind="notbuilt" /> or <Status kind="designed" />: not in the code.
