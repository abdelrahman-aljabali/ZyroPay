# Implementation Status

Last updated: 2026-10-31. Staging (testnets) runs on zyropay.online, documented at https://docs.zyropay.online, a fresh instance with an empty database created 2026-10-30; production is not deployed. The history of each item is in `git log`.

Status:

- **done:** implemented, tested, and where it says "live", run against the real service.
- **partial:** implemented and tested locally, but not yet run where it matters (device, real provider, mainnet).
- **open:** not started, or waiting on an external dependency.

## Open items that block a launch

- Run wallet import, Cardano signing and the Always Ask flow on real devices with a development build (EAS).
- Live runs still missing on preprod: a `not_delivered` refund, an auto-pay top-up and revoke (https://docs.zyropay.online/evidence/). Done live: the escrow lifecycle lock, SubmitResult, Withdraw; the dishonest-seller refund (proof `mismatch`, passkey refund); the Masumi registration and the x402 seller's own identity; a paid Sokosumi Task; the sub-hire chain (user pays `ae026a…bd41`, seller pays the specialist `07096a…891a`); a recipient-allowlist denial from ChatGPT, then the same send allowed after a policy change (`abc838…c26a`); `find_agents`/`verify_agent` from ChatGPT; Auto-pay on Cardano from the app, create (`add08c…f8a8`) and a no-tap x402 payment by ChatGPT (`987cb7…e93a`).
- Production: its own Neon branch, mainnet secrets, custom domains (the passkey rpId is chosen once), Sentry DSNs.
- Webhooks registered with Helius and Alchemy; Expo push credentials; Transak keys.
- Security review and threat-model sign-off (`docs/SECURITY.md`).
